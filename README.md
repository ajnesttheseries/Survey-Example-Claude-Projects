# ผลงานที่คนไทยสร้างด้วย AI — เก็บ วิเคราะห์ และจัดแสดง

รวบรวมผลงานที่ผู้คนนำมาแชร์ในโพสต์ Facebook แล้วแปลงเป็นแคตตาล็อกที่ค้นได้จริง

**โพสต์ต้นทาง:** https://www.facebook.com/groups/1745892855948687/posts/2323047211566579/

## ผลลัพธ์

| ไฟล์ | คืออะไร |
|---|---|
| `ผลงาน-AI-จากคอมเมนต์-Facebook.xlsx` | แคตตาล็อก 147 ผลงาน 16 หมวด · 3 ชีต (แคตตาล็อก / สรุปตามหมวดหมู่ / วิธีทำและข้อจำกัด) |
| `site/` | เว็บนิทรรศการที่ deploy ขึ้น GitHub Pages (เอกสาร HTML เต็มใบ + ไฟล์ Excel ให้ดาวน์โหลด) |
| `gallery/index.html` | เว็บเดียวกันในรูปชิ้นส่วนสำหรับ Claude Artifact (ไม่มี `<!doctype>`/`<head>` เพราะระบบห่อให้) |
| `data/catalog.json` | ข้อมูลแคตตาล็อกที่จัดหมวดแล้ว ใช้ป้อนทั้ง Excel และเว็บ |

## ขั้นตอน

```
โพสต์ Facebook
  └─ tools/fb-comment-extractor.js   รันใน DevTools Console → JSON
       └─ tools/build_catalog.py     รวม 3 ไฟล์ ตัดซ้ำ จัดหมวด → data/catalog.json
            ├─ tools/make_excel.py     → .xlsx
            └─ tools/make_gallery.py   → site/ (GitHub Pages) + gallery/ (Artifact)
```

ดึงคอมเมนต์ต้องรันเองในเบราว์เซอร์ เพราะ Facebook ปิด Groups API สำหรับอ่านคอมเมนต์
ตั้งแต่ปี 2020 วิธีใช้อยู่ใน [`tools/README.md`](tools/README.md)

## เว็บไซต์

https://ajnesttheseries.github.io/Survey-Example-Claude-Projects/

Deploy อัตโนมัติด้วย `.github/workflows/pages.yml` ทุกครั้งที่ push
โดย CI รัน `tools/make_gallery.py` สร้างเว็บใหม่จาก `data/catalog.json`
เว็บที่ออนไลน์จึงตรงกับข้อมูลในรีโปเสมอ

## ตัวเลข

- คอมเมนต์ที่อ่าน 1,329 (รวมจากการรัน 3 ครั้ง ได้ 470 / 859 / 1,339 แล้วตัดซ้ำด้วย commentId)
- ผลงานที่คัดเข้าแคตตาล็อก 147 ชิ้น ใน 16 หมวด
- ลิงก์ที่กดเข้าได้ 138 · ลิงก์ที่ Facebook ตัดจนใช้ไม่ได้ 9

## ทดสอบ

```bash
npm install
npm test          # ตรรกะการอ่าน DOM 23 เคส + ตรวจไฟล์ Excel 18 เคส
```

การตรวจ Excel ไม่ได้ใช้ LibreOffice recalc เพราะ LibreOffice ในสภาพแวดล้อมนี้
คำนวณไม่สำเร็จแม้ไฟล์ที่มีสูตรเดียว `tools/verify_excel.py` จึงอ่านสูตรตรง ๆ
แล้วตรวจช่วงอ้างอิง ชื่อหมวด ฟังก์ชันที่ใช้ และสถานะลิงก์เทียบกับข้อมูลจริงแทน
ไฟล์ตั้ง `fullCalcOnLoad` ไว้ Excel จึงคำนวณสูตรให้ทันทีที่เปิด

## ข้อจำกัด

- ลิงก์ 9 รายการใช้ไม่ได้ เพราะ Facebook ตัดข้อความลิงก์ยาวด้วยจุดไข่ปลา และสคริปต์
  เก็บเฉพาะข้อความที่แสดง ไม่ได้เก็บ `href` จริง — ลิงก์ App Store กู้คืนจากเลข app id ได้
  แต่ Play Store และ Chrome Web Store กู้ไม่ได้
- ภาพปกในเว็บเป็นลายริโซที่ generate จากชื่อผลงาน **ไม่ใช่ภาพหน้าจอจริง**
- คำอธิบายผลงานสรุปจากข้อความที่เจ้าของเขียน ไม่ได้เข้าไปทดลองใช้จริง
- คอมเมนต์ที่ Facebook ซ่อนหรือกรองเป็นสแปมไม่อยู่ใน DOM จึงเก็บมาไม่ได้
