# เครื่องมือดึงคอมเมนต์จากโพสต์ Facebook

## ทำไมต้องรันเอง

Claude ดึงให้โดยตรงไม่ได้ ด้วยเหตุผล 2 ข้อที่แก้ที่ฝั่ง Claude ไม่ได้:

1. **Network policy ของ Claude Code บล็อก `facebook.com` ทุก host**
   (`www` / `m` / `mbasic` / `graph` ตอบ `403 CONNECT — policy denial` หมด)
   แก้ได้ทางเดียวคือเปลี่ยน network policy ตอนสร้าง environment
   ดู https://code.claude.com/docs/en/claude-code-on-the-web

2. **Facebook ปิด Groups API สำหรับอ่านโพสต์/คอมเมนต์ตั้งแต่เมษายน 2020**
   ต่อให้กลุ่มเป็น Public ก็ตาม — เหลือเฉพาะแอปที่ **แอดมินกลุ่ม** ติดตั้งเอง
   พร้อมสิทธิ์ `groups_access_member_info` ซึ่งต้องผ่าน App Review
   ("Public" ในบริบท Facebook Group ไม่ได้แปลว่าเรียก API ได้โดยไม่ล็อกอิน)

สคริปต์นี้จึงทำงานในเบราว์เซอร์ของคุณเอง ที่ล็อกอิน Facebook อยู่แล้ว
ไม่มีการส่งข้อมูลออกไปที่ไหน — อ่าน DOM แล้วเซฟไฟล์ลงเครื่องคุณตรง ๆ

## วิธีใช้

1. เปิดโพสต์ในเบราว์เซอร์ (Chrome / Edge / Firefox บนคอมพิวเตอร์)

   แนะนำให้เปิดเป็น **permalink เดี่ยว** จะได้ไม่ปนคอมเมนต์จากโพสต์อื่นในฟีดกลุ่ม:

   ```
   https://www.facebook.com/groups/1745892855948687/posts/2323047211566579/
   ```

2. **เปลี่ยนตัวกรองคอมเมนต์เป็น "ความคิดเห็นทั้งหมด"** (All comments)

   กดที่เมนูข้าง ๆ คำว่า "เกี่ยวข้องมากที่สุด" / "Most relevant" แล้วเลือก
   "ความคิดเห็นทั้งหมด" — **ขั้นตอนนี้สำคัญมาก** ค่าเริ่มต้นของ Facebook
   จะซ่อนคอมเมนต์บางส่วนไว้ ถ้าไม่เปลี่ยนจะได้ข้อมูลไม่ครบ

3. เปิด DevTools Console: กด `F12` แล้วไปแท็บ **Console**
   (Mac: `Cmd + Option + J`)

4. ครั้งแรก Chrome จะไม่ให้วางโค้ด ต้องพิมพ์ `allow pasting` แล้ว Enter ก่อน

5. เปิดไฟล์ [`fb-comment-extractor.js`](./fb-comment-extractor.js) copy ทั้งไฟล์
   วางลง Console แล้ว Enter

6. **รอ** — สคริปต์จะไล่กด "ดูความคิดเห็นเพิ่มเติม" และ "ดูการตอบกลับ" เอง
   จนหมด ระหว่างนี้อย่าเลื่อนจอหรือสลับแท็บ
   โพสต์ที่มีคอมเมนต์หลายร้อยอันอาจใช้เวลา 2–5 นาที
   ดูความคืบหน้าได้จาก log ใน Console

7. เสร็จแล้วจะดาวน์โหลด 2 ไฟล์อัตโนมัติ:
   - `fb-comments-<postId>.csv` — เปิดใน Excel ได้เลย (มี BOM รองรับภาษาไทย)
   - `fb-comments-<postId>.json` — สำหรับเอาไปประมวลผลต่อ

## คอลัมน์ที่ได้

| คอลัมน์ | ความหมาย |
|---|---|
| `index` | ลำดับตามที่ปรากฏบนหน้าจอ |
| `depth` | `0` = คอมเมนต์หลัก, `1` = ตอบกลับ, `2` = ตอบกลับของตอบกลับ |
| `author` | ชื่อผู้แสดงความคิดเห็น |
| `text` | เนื้อความ |
| `relativeTime` | เวลาแบบที่ Facebook แสดง เช่น `2 ชม.` (ไม่ใช่ timestamp จริง) |
| `reactions` | จำนวนรีแอ็กชัน (ว่างได้ถ้าไม่มี) |
| `commentId` | ID ของคอมเมนต์ |
| `profileUrl` | ลิงก์โปรไฟล์ (ตัด tracking param ออกแล้ว) |
| `permalink` | ลิงก์ตรงไปยังคอมเมนต์นั้น |

## ข้อจำกัดที่ควรรู้

- **`relativeTime` ไม่ใช่วันที่จริง** Facebook แสดงเป็น "2 ชม." / "5 นาที"
  ถ้าต้องการ timestamp แน่นอน ต้องเอา `permalink` ไปเปิดทีละอัน
- **คอมเมนต์ที่ถูกซ่อน/กรองสแปม จะไม่ถูกดึง** เพราะมันไม่อยู่ใน DOM
  Facebook มักซ่อนไว้ท้ายสุดใต้ "ดูความคิดเห็นเพิ่มเติม" อีกชั้น
- **รูปภาพ / สติกเกอร์ / GIF ในคอมเมนต์** จะได้เป็นข้อความว่าง
- สคริปต์นี้ยึดกับ ARIA role/label ซึ่งเสถียรกว่าชื่อ class
  แต่ Facebook เปลี่ยน UI บ่อย — ถ้าวันหนึ่งพัง ดูหัวข้อถัดไป

## การแก้ปัญหา

**ดึงได้ 0 คอมเมนต์**

Facebook อาจเปลี่ยน `aria-label` ลองรันคำสั่งนี้ใน Console เพื่อดูของจริง:

```js
[...document.querySelectorAll('div[role="article"]')]
  .map(e => e.getAttribute('aria-label'))
  .filter(Boolean)
  .slice(0, 10);
```

ถ้าได้ label รูปแบบอื่น ให้แก้ `COMMENT_LABEL_RE` ในสคริปต์ให้ตรง

**ได้ไม่ครบ / หยุดกลางคัน**

เพิ่มค่าใน `CFG` ที่หัวไฟล์:
```js
pauseMs: 2000,     // เน็ตช้า ให้รอนานขึ้น
maxRounds: 1500,   // คอมเมนต์เยอะมาก
```

**Console ขึ้น "ชนเพดาน maxRounds"** — แปลว่ายังขยายไม่หมด เพิ่ม `maxRounds` แล้วรันใหม่

## ทดสอบ

logic การอ่าน DOM มี unit test ครอบด้วย jsdom (23 เคส):

```bash
npm install
npm test
```

ครอบเรื่อง: การแยกคอมเมนต์ออกจากตัวโพสต์, ระดับ reply ซ้อนชั้น,
การกันข้อความ reply รั่วเข้าคอมเมนต์แม่, การตัดข้อความซ้ำจาก `div` ซ้อน,
การ escape CSV, การตัด tracking param และการเลือกปุ่มขยายโดยไม่กดปุ่ม "ถูกใจ"

## ทางเลือกอื่น

ถ้าคอมเมนต์ไม่เยอะ วิธีที่เร็วกว่าคือกดขยายให้ครบแล้ว copy ข้อความทั้งหมด
ส่งให้ Claude จัดรูปแบบ / สรุป / แยกประเด็นให้ — ไม่ต้องใช้สคริปต์เลย
